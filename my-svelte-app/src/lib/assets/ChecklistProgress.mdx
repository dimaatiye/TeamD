<Meta title="Checklist/The Submit Gate"/>

In this web page, the checklist counter is only updated once the "Submit" button has been pressed. Any checklist option can be selected, but no progress will be recorded until the submit button is selected. This is processed by using derived variables that update with the amount of selected checklist items. A variable for the live count of checked items is assigned to the amount of checklist items in an array of checklist items have their "done" variable set to "true". The total number is also given a derived variable which is assigned to the total number of elements in the items array. Once the "Submit" button is pressed, the displayed counter is updated using a derived variable of the current selected. The checklist array has a function that filters the array to selected elements and then calculates the percentage based on that. This function returns the overall percentage value that is passed to the displayed percentage. The current count of selected items and overall percentage updates when the "Submi" button is pressed. This method keeps the calculation and submit process decoupled and simplified.
